# Object Detection from Scratch

A hands-on repository for learning and implementing **object detection from first principles**.

The goal is to understand the fundamental ideas behind modern object detection systems by building them step by step rather than relying on high-level detection frameworks.

## Current Progress

- Pascal VOC 2007 dataset exploration
- Object detection annotations and bounding boxes
- Bounding box visualization

## Dataset

Experiments currently use the **Pascal VOC 2007** dataset.

Dataset files are not included in this repository.
